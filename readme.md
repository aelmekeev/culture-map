# The Culture Map

An interactive visualization of Erin Meyer's Culture Map scales. 

## About the Project

This project provides a visual, interactive way to explore and compare cultural differences between various countries based on the eight behavioral scales defined in [Erin Meyer's book, *The Culture Map*](https://erinmeyer.com/books/the-culture-map/). 

The scales analyze how different cultures approach:

- **Communicating** (Low-Context vs. High-Context)
- **Evaluating** (Direct Negative Feedback vs. Indirect Negative Feedback)
- **Persuading** (Principles-First vs. Applications-First)
- **Leading** (Egalitarian vs. Hierarchical)
- **Deciding** (Consensual vs. Top-Down)
- **Trusting** (Task-Based vs. Relationship-Based)
- **Disagreeing** (Confrontational vs. Avoids Confrontation)
- **Scheduling** (Linear-Time vs. Flexible-Time)

### Features

- **Absolute View:** See exactly where one or multiple countries fall across all eight cultural dimensions. 
- **Relative View:** Select a "base country" (for example, your own) to instantly visualize how other cultures differ *relative* to your cultural baseline, highlighting potential friction points.
